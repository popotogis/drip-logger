# Drip Logger (Web App)

理想のコーヒー抽出を追求し、詳細な記録を残すためのドリップログ・ツールです。  
ブラウザ上で動作し、タイマーと連動したリアルタイムな抽出ログの作成が可能です。

## 主な機能

### 1. 詳細なパラメータ記録
コーヒーを淹れるために必要なあらゆる情報を網羅的に記録できます。

- **コーヒー豆の情報**: 名称、焙煎所、焙煎度（浅・中・深）、産地、精製方法（Washed / Natural等）、品種（Geisha / Bourbon等）、焙煎日
- **抽出レシピ**: 豆の分量、湯量、湯温、挽き目、使用する器具（グラインダー、ドリッパー、フィルター）、メモ
- **抽出ステップ**: 注湯タイミングと湯量の詳細な計画

### 2. リアルタイム・タイマー連携
作成したレシピに従って抽出を実行できます。

- 抽出開始と同時にタイマーが作動。
- 注湯ステップごとにボタンをタップすることで、**計画対比のラップタイム（実績時間）**を自動記録。
- 抽出完了後には、テイスティングノート（感想）も併せて保存可能。

### 3. Magic Code (レシピ共有)
Base64 エンコードを利用したサーバーレスなレシピ共有機能です。

- **エクスポート**: 自分が作成したレシピを一瞬で「共有用コード」としてコピー可能。
- **インポート**: 共有されたコードを読み込むだけで、他の人のレシピを自分の環境に復元。

### 4. Markdown エクスポート
記録した抽出ログは、美しい **Markdown 形式**で出力できます。  
ブログ、Scrapbox、Notion などへの転記や、自身のアーカイブとして最適です。

## 技術構成
- **Frontend**: Flutter (Web)
- **State Management**: [Riverpod](https://riverpod.dev/)
- **Database**: [Sembast](https://github.com/tekartik/sembast.dart) (ブラウザのローカルストレージ)
- **Design**: Material 3

## 使い方
1. **豆を登録**: 「Manage Beans」から使用する豆の情報を登録します。
2. **レシピを作成**: 豆の量やステップごとのタイミングを設定します。
3. **ドリップ実行**: レシピ詳細からタイマーをスタートさせ、画面の指示に従いドリップします。
4. **ログを保存**: 実績を確認し、感想を添えて保存します。必要に応じてコードを共有したり、Markdown で出力します。
